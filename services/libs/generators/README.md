# Ali.Delivery.Generators

Генератор кода для маппинга Enum и Dictionary сущностей.

## Установка
Установите пакет через NuGet:
dotnet add package Ali.Delivery.Generators


## Использование
Этот генератор предназначен для улучшения работы с Enum и Dictionary через автоматическую генерацию кода маппинга.
